# Stable QR codes for chore tickets

A chore ticket's QR code identifies the child and the chore, not a single printing, so every reprint of "Make your bed" for the same child carries the same code. This lets a lost or old slip still be handed in, makes it obvious which child earns the stars without the child having to say who they are, and allows slips to be laminated and reused instead of printed every day. Quiz tickets, by contrast, get a unique code per quiz because each one has different content.

## Consequences

- A code can't tell you which day a slip was printed, so the system decides what a hand-in counts towards by looking at the child's current open ticket for that chore.
- Once physical slips exist, changing the code format means reprinting or relaminating every chore slip.
