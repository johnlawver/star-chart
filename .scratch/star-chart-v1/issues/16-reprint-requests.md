# 16: Reprint Requests

**What to build:** A child with an open ticket taps "I lost it" at the Observatory, which creates a **Reprint Request**. A grown-up or guest approves or declines it in the Control Center. Approval reprints exactly the same ticket (same code and, for a quiz, same content) on that Observatory's Printer.

**Blocked by:** 06 (Rejection, Dismissal and every scan result), 10 (Quizzes)

**Status:** ready-for-agent

- [ ] From the category where they hold an open ticket, a child can send a Reprint Request.
- [ ] Grown-ups and guests see pending Reprint Requests and can approve or decline them.
- [ ] Approval prints the same code and content. Decline prints nothing.
- [ ] If the Printer is offline when a request is approved, the approval fails with a clear reason and nothing is queued.
