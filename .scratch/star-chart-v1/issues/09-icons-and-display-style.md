# 09: Icons and Display Style

**What to build:** A built-in library of bold, black-and-white **Icons**. Grown-ups choose an icon for each category and chore (and later topics). Children whose Display Style is pictures see big icons on their Observatory buttons and on printed tickets. Children set to words see text.

**Blocked by:** 04 (Print a chore ticket)

**Status:** ready-for-agent

- [ ] A built-in icon library ships with the app, including a starter set suitable for common chores.
- [ ] Grown-ups pick an icon when creating or editing a category or chore.
- [ ] A child set to pictures sees icons on the Observatory and a large icon on printed tickets. A child set to words sees text.
- [ ] Everything sent to a Printer is pure black and white, with no greys.
